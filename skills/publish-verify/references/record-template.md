# 公開の記録(様式)

1つの公開につき1ファイル。`publish-verify.sh post … --record <このファイル>` が「突き合わせ」の節を書き足す。ほかの欄は手で書く。

```
# 公開の記録: <公開物の名前> / <日付>
対象: <手元のフォルダの名前> → <公開先のURL>
承認: <だれが・いつ・どの範囲で公開を認めたか>
公開の前の関門(pre): 全部 OK / NG <件数>(<日時>)
公開前の検索: NG=<n> WARN=<n> / WARN の扱い: <1件ずつ理由>
目で見た画像・添付: <ファイル名。なければ「対象なし」>
(ここに post の出力が入る: clone・最新のコミット・cmp・作者メール・Pages)
未確認: <確かめていない範囲を書く。「なし」とは書かない>
```

書かないもの: 見つかった鍵・メール・検索語の値、手元の絶対パス、トークン。
