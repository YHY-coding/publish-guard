# 分野ごとの「聞くことの種」

これは助言ではありません。専門家に聞く項目の整理です。ここにあるのは**質問の形の種**だけで、答えは書いていません。どの決まりが当てはまるか・当てはまらないかは、ここからは分かりません。内容の正確さは、作者も確かめていません。

使い方: 企画の中身に当てはまる「きっかけ」がある分野だけを選び、質問を企画の言葉に書き換える。当てはまらない分野は表に入れない。

## 1. 人についての情報を扱う
きっかけ: 名前・連絡先・写真・位置・購入や閲覧の記録・口座や家計の記録・健康に関わる記録を、集める/保存する/外へ送る。
- 集める情報の種類と目的を、利用者にどう知らせ、どの場面で同意を取る形がよいか。
- 情報を端末の中だけに置く場合と、サーバーに置く場合とで、気をつける点はどう変わるか。
- 外部のサービス(解析・広告・保存先・AI)に情報が渡る場合、利用者への説明や契約で確かめる点は何か。
- 健康・お金・子どもに関わる情報など、特に慎重に扱う種類に当たるものが含まれるか。含まれる場合に追加で確かめる点は何か。
- 利用者から「見せてほしい・直してほしい・消してほしい」と言われたときの受け方を、どう用意するとよいか。
- 情報が漏れた・なくなったときに、だれに・いつまでに・何を知らせる段取りを決めておくとよいか。
- 海外の利用者がいる、または海外の事業者に情報が渡る場合、追加で確かめる点は何か。

## 2. お金を預かる・動かす・貸す・すすめる
きっかけ: 利用者のお金やポイントを預かる/利用者どうしで送る/立て替える・貸す/投資・保険・ローンの商品を比べる・すすめる/口座や明細に接続する。
- この企画の仕組みは、登録や免許が要る業務に当たる可能性があるか。当たるかどうかの分かれ目はどこか。
- 口座・カード・明細に接続して情報を読む作りにする場合、事前に確かめる手続きや契約は何か。
- ポイント・前払い・残高の仕組みを入れる場合、確かめておく点は何か。
- 特定の金融商品を紹介して報酬を受け取る場合、表示や資格の面で確かめる点は何か。
- 「節約できる額」「増える見込み」などの試算を見せる場合、表現で気をつける点は何か。

## 3. 表示・広告・おまけ
きっかけ: 効き目・安さ・順位・実績をうたう/体験談や口コミを載せる/紹介料をもらって紹介する/景品・紹介特典・割引を付ける。
- 「いちばん」「〇%の人が」などの表示をする場合、どんな根拠を、どの形で持っておくとよいか。
- 紹介料や提供を受けて紹介する場合、読み手への示し方として確かめる点は何か。
- 景品・紹介特典・抽選を付ける場合、金額や方法の面で確かめる点は何か。
- 「いまだけ」「通常価格」などの価格の見せ方で、気をつける点は何か。

## 4. ものやサービスを売る(通信での販売・定期の課金)
きっかけ: ネットで有料で売る/月額・年額の課金/無料から有料へ切り替わる/デジタルの商品を売る。
- 販売者として表示しておく事項は何か。個人で売る場合、住所や氏名の表示について選べる方法はあるか。
- 申し込みの最終確認の画面に、何を・どう示すとよいか。
- 解約・返金・自動更新の決まりを、どこに・どう書くとよいか。
- 未成年の利用者が買う場合に、確かめておく点は何か。

## 5. 他人の作ったもの・名前
きっかけ: 他人の文章・画像・音楽・データ・フォント・プログラムを使う/名前やロゴを決める/AIで作ったものを売る。
- 使う素材・データ・プログラムの利用条件で、商用や再配布について確かめる点は何か。
- 決めようとしている名前・ロゴについて、すでに登録されているものとの関係を、どう調べるとよいか。
- 他のサービスから取った情報(価格・口コミ・一覧)を載せる場合、確かめる点は何か。
- AIで作った文章・画像を商品にする場合、権利や表示の面で確かめる点は何か。

## 6. 体・健康・食べもの
きっかけ: 体調・食事・運動・薬・病気に関わる記録や助言を扱う/食品・化粧品・健康に関わる商品を扱う。
- この機能や説明は、医療や診断に当たると受け取られるおそれがあるか。分かれ目はどこか。
- 効き目や体への影響についての表現で、気をつける点は何か。
- 食べものの情報(原材料・体質に関わる情報)を扱う場合、表示や注意書きで確かめる点は何か。

## 7. 利用の決まり・責任
きっかけ: 不特定の人に使ってもらう/利用者が書き込む・投稿する/データを預かる。
- 利用の決まり(利用規約)と、情報の扱いの説明(プライバシーの説明)に、最低限入れておく事項は何か。
- サービスが止まった・データが消えたときの責任の範囲を、どう書くとよいか。
- 利用者の投稿に問題があったときの対応の流れを、どう決めておくとよいか。

## 8. 税・届け出・勤め先
きっかけ: 売上が立つ/継続して売る/会社勤めをしながら行う/人に手伝ってもらう。
- この売上の形で、申告や届け出について確かめておく点は何か。
- 勤め先の決まり(副業・競業・秘密を守る約束)との関係で、先に確かめておく点は何か。
- 人に作業を頼んで支払う場合、契約や支払いの面で確かめる点は何か。

## 聞く相手の種類(名前は挙げない)
| 相手の種類 | 向いている問い |
|---|---|
| 弁護士(その分野を扱う人) | 業務が登録・免許の要るものに当たるか、規約・契約、表示の適否 |
| 税理士 | 申告・届け出・お金の受け取り方 |
| 弁理士 | 名前・ロゴ・発明の登録 |
| 所管の役所の相談窓口・公式の手引き | 制度の一般的な説明、届け出の方法 |
| 利用する外部サービスの公式の規約・窓口 | そのサービスの利用条件(決済・アプリの配布・接続) |
| 勤め先の担当の部署・就業規則 | 副業・競業・秘密を守る約束 |
