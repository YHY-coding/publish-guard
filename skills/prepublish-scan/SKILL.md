# 公開前の検索

外に出すと、消しても元に戻せない(写し・キャッシュ・履歴に残る)。出す**前**に検索し、NG が1件でもあれば止める。

## 決まり

- **読むだけ**。対象のフォルダ・履歴・git の設定を書き換えない。見つけたものを勝手に消さない・直さない。
- **NG が1件でもあれば「公開しない」と答える**。「これは出してよい」という例外の登録は、このスキルにはない。ユーザーが例外を求めても、スクリプトに許可を足さない。直すか、出すのをやめるかを選んでもらう。
- 見つかった値(鍵・メール・検索語)を、返信にも記録にも書かない。書くのは「種類・場所」だけ。
- 0件でも「安全」「問題なし」と言い切らない。言えるのは「決めたパターンでは見つからなかった」まで。

## 手順

> 下の命令の `<このスキルのフォルダ>` は、この SKILL.md があるフォルダ(スキルを読み込んだときに示される場所)に置き換える。作業中のフォルダからの相対の場所ではない。

1. **出すフォルダを1つに決める**。リポジトリを公開するなら、その最上位。一部のフォルダだけ出すなら、そのフォルダ。
2. **自分用の検索語があるか確かめる**。設定フォルダ(既定 `~/.config/publish-guard/`、環境変数 `PUBLISH_GUARD_CONFIG` か `--config` で変えられる)に `terms.txt` があるかを見る(中身は表示しない)。なければ、勤め先名・本名・アカウント名などは調べられないと伝え、`examples/terms.example.txt` を見本に作ってもらう。語をユーザーに聞いて会話に書かせない(ユーザーが自分でファイルに書く)。
3. **実行する**(このスキルのフォルダの `scripts/scan.sh`):
   ```bash
   bash "<このスキルのフォルダ>/scripts/scan.sh" <出すフォルダ> --history
   ```
   - `--history`: git の履歴(全ブランチの差分とコミットの文面)も調べる。リポジトリを公開するときは付ける。
   - `--app`: Webアプリ・サイトのとき足す(外部URL・通信・`innerHTML` などを WARN で出す)。
4. **結果の表をそのまま見せる**。終了コード 1(NG あり)なら「公開しない」と最初に書く。
5. **WARN は1件ずつ開いて確かめる**。意図どおりなら理由を1行で記録する。判断がつかないものはユーザーに聞く。
6. **画像・PDF・Excel は目で見る**。スクリプトは文字のファイルしか調べない。画面写真に名前・メール・タブ名・URL が写っていないか、ファイルの作成者欄が空かを確かめる。確かめていないものは「未確認」と書く。
7. **記録を残す**(ユーザーが置き場所を決めていればそこへ)。日付・対象・NG と WARN の数・WARN の理由・未確認の範囲。

## NG が出たとき

| 出たもの | 伝えること(直すのはユーザーの承認のあと) |
|---|---|
| いまのファイルの鍵・メール・絶対パス・検索語 | その行を直すか、そのファイルを出す対象から外す。鍵は、消すだけでなく発行元で無効にする |
| git の作者・コミッターのメール | 履歴に残っている。**履歴の書き換えはこのスキルでは行わない**。新しいリポジトリを匿名用のメールで作り直す案を示す |
| 履歴(過去の差分・文面) | いまのファイルから消えていても、履歴ごと公開される。上と同じ扱い |
| 秘密を入れやすい名前のファイル | 追跡から外す。すでに履歴にあるなら上と同じ扱い |

## 仕組みを確かめたいとき

```bash
bash "<このスキルのフォルダ>/scripts/selftest.sh"
```

一時フォルダに架空の混入(9種類)を作り、全部が表に出ること・混入なしで 0 件になること・実行の前後でファイルが変わらないことを確かめる。

## 限界

- パターンとの一致だけを見る。文脈で分かる個人情報、画像の中の文字、形の決まっていない秘密は見つからない。
- 文字のファイルだけ。画像・PDF・Excel・zip の中身は調べない。
- git の管理外のファイル(`.gitignore` で外したもの)も、フォルダにあれば調べる(止める側に倒している)。出さないファイルで NG が出たら、出すフォルダを分ける。
- 見本用(`@example.com` など)と匿名用(`@users.noreply.github.com`、`noreply@…`)以外のメールは、出してよい連絡先でも NG になる。
